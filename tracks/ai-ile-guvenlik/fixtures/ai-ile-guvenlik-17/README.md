# ai-ile-guvenlik-17 · Güvenlik Ajanına Karşı Kırmızı Takım (Anti-Triage & Evasion) Verisi (SENTETİK)

Bu dizindeki tüm dosyalar **sentetik** eğitim verisidir; yalnız güvenlik ajanlarının kaçınma (`evasion`) ve bağlam boğma (`token sponge`) tekniklerine karşı dayanıklılığını ölçmek için kullanılır.

- `adversarial_kod_ornekleri.json`: Sahte denetim onayı yorumu, token süngeri dolgusu ve yem (`decoy`) yorumlarla gizlenmiş sentetik kod örnekleri.
