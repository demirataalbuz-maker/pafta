# ai-ile-guvenlik-12 · Log Enjeksiyonu ve SOC Triyaj Verisi (SENTETİK)

Bu dizindeki tüm dosyalar **sentetik** eğitim verisidir; gerçek kurum logu veya canlı saldırı trafiği içermez.

- `soc_olay_akisi.jsonl`: `user_agent` veya `kullanici` alanında dolaylı istem enjeksiyonu (`indirect prompt injection`) barındıran sentetik SOC olay kayıtları.
- `model_triyaj_kararlari.json`: Korumasız modelin zehirli log satırı yüzünden bastırdığı (`"temiz"` dediği) sentetik triyaj kararları.
