# ai-ile-guvenlik-01 · Sentetik Örnek Veri

Bu klasördeki dosyalar **sentetik** eğitim verisidir; canlı zafiyet tarayıcısı veya gerçek model yanıtı değildir:
- `model_yanit_adaylari.jsonl`: Modelin serbest metin veya kod çiti içinde ürettiği sentetik bulgu yanıtları.
- `sema_kurallari.json`: Güvenlik bulgusu JSON şeması ve izin verilen değer kümeleri.
- `yeniden_deneme_kuyrugu.json`: Şema ihlallerinde yeniden deneme bütçesi sınaması için sentetik kuyruk.
