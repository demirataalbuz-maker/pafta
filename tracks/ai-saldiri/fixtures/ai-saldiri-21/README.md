# Görünür AI-SSRF senaryoları
veri/ssrf-senaryolari.json ve veri/http-akisi.txt elle yazılmış sentetik örneklerdir, canlı kayıt değildir. Görevler bu dosyaları okuyup deneye ait dinamik portları kullanır; ilk iki görevde HTTP gerçektir, model fixture'dır. Üçüncü birleşik görev yerel modeli gerçekten çağırır. Çalıştır dosyaları ve gerçek örnek sonucu gösterir. Geçici örnek kopyası sonraki çalıştırmada yenilenir, kalıcılık yoktur. Son görevin ayrı calisma/ai-saldiri-21/url-notu.txt dosyası ise kalıcıdır. Gizli testler ayrıdır. Statik .test hostları yalnız deneye ait loopback servislere gider; gerçek iç ağ veya internet DNS rebinding deneyi yapılmaz. Sadece bu deneyin sunucuları kapanır.
