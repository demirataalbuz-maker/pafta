# Görünür sentetik hiyerarşi verisi
veri/hiyerarsi.json elle yazılmış olay, yapılandırılmış kural ve sorgulardır; canlı model kaydı değildir. İlk görev rol/kaynak sırasını, ikinci aynı kapsamdaki çatışmayı, üçüncü referans kararı aynı dosyadan işler. Çalıştır veriyi/sonucu gösterir. Koddan aynı çalıştırmada kopya düzenlenebilir; sonraki çalıştırmada kaynak yeniden kopyalanır, kalıcılık yoktur. Gizli testler bağımsızdır. Son görev gerçek Ollama modelleriyle ölçer; developer etiketi system mesajına eşlenir ve bu bir native developer-kanalı deneyi değildir. Beklenen politika ile gözlenen model davranışı ayrı tutulur. Uyum başarı koşulu değildir, teknik hata kabul değildir.
