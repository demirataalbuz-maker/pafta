# Görünür sentetik paket önerisi
veri/paket_onerisi.txt canlı model kaydı değildir; yazım hatası ve hayalî eğitim adı içerir. Dosyadaki komutları çalıştırma: görev yalnız metni okur, hiçbir paket kurmaz. veri/denetim.json öneriler ve yerel onaylı adları içerir. İlk üç görev aynı dosyaları mevcut hazirla() ile geçici klasöre kopyalar. Çalıştır ham metni/JSON değerlerini gösterir. Koddan aynı çalıştırmada kopyayı değiştirebilirsin; sonraki çalıştırmada örnek yenilenir, kalıcılık yoktur. Gizli testler bağımsızdır. Son deney canlı yerel modelden öneri alır; allow-list dışı olmak zararlı/var olmayan olmak demek değildir. Import adı dağıtım adıyla her zaman aynı değildir.
