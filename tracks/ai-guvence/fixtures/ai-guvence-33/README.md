# Görünür sentetik metodoloji verisi
kapsam.json ve bulgular.json elle yazılmış eğitim örnekleridir; gerçek olay veya canlı model sonucu değildir. Görevler aynı JSON dosyalarından kapsam kontrolü, öğretim amaçlı etki+erişim puanlama ve kategori birleştirme yapar. Kapsam.json bir yetkilendirme belgesi veya gerçek sisteme erişim izni vermez. Çalıştır ham JSON değerlerini ve sonucu gösterir. Aynı çalıştırmada kopyayı koddan değiştirebilirsin; çalışma klasörü geçicidir, sonraki çalıştırmada kaynak örnek yenilenir. Gizli testler bağımsızdır. Son görev yerel modelle üç probe'u beşer kez çalıştırır; tutarlılık yalnız bool sonuçların aynı olmasıdır, modelin genel güvenliğinin veya tam metinlerin aynı olduğunun kanıtı değildir. Teknik hatalar kabul değildir.
