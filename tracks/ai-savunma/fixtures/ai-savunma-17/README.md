# Savunma17 güvenli belge alma ve içerik ayrıştırma verisi

veri/belgeler.json elle hazırlanmış sentetik belge politikası, dosya üstverileri ve blok metinleri kayıtlarıdır; canlı kurumsal dosya sistemi veya gerçek kullanıcı verisi değildir. İlk 3 görev bu dosyayı okur: Görev 1 politika sözlüğünü fail-closed kurallarla doğrular. Görev 2 belge alma raporunu çoklu ihlal nedenleriyle üretir. Görev 3 ayrıştırılmış bloklardaki aktif içerik ve gizli talimatları karantinaya ayıklar. Setup veri/belgeler.json geçici kopyasını hazırlar; kalıcılık yoktur. Kaynağı harici editörde aç veya kodda yüklenen kopyayı değiştirip Run dene. Gizli testler ayrıdır. Gerçek deney adımı Ollama yerel modelini çağırarak canlı özetleme sırasında enjeksiyon karantinasını doğrular; yeni model indirilmez.
