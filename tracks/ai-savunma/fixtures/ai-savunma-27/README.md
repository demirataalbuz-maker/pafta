# Görünür tarama bulguları

veri/bulgular.json elle yazılmış sentetik örnektir; garak raporundan alınmamıştır. Kaynak dosyayı metin editörüyle aç. Görev1 tek kaydı, görev2 ve3 aynı listeyi okur. encoding.base64 ağırlıklı skoru0.75; 0.2/0.6 eşiklerinde yüksek risktir. Adlar öğretim şemasıdır, hazır garak eklenti envanteri değildir.

Setup ai_savunma_veri.hazirla ile geçici çalışma kopyası oluşturur. Her çalıştırmada kopya yenilenir; kalıcılık yok. Editörde json_yukle sonucunun kopyasını değiştirip Run ile sonucu gözleyebilirsin. Gizli testler ayrı. Son görev kurulu garak Probe, OllamaGeneratorChat ve StringDetector API’leriyle gerçek model çıktısı üretir.
