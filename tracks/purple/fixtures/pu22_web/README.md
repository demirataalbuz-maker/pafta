# pu22 · Görünür Sentetik Örnekler

`ornekler.json` **sentetiktir**: girdiler elle yazılmıştır, hiçbir sunucuya gönderilmez.

- `html` (Görev 1): Kaçışlanacak metinler.
- `sablonlar` (Görev 2): `[şablon, izinli alanlar]` çiftleri.
- `xml` (Görev 3): Metin olarak XML belgeleri; örnek kod bunları UTF-8 baytlarına çevirir.

Setup her Çalıştır/Kontrol Et adımında eksik dosyaları kopyalar; **kalıcılık yoktur**. Son görev bu dosyayı kullanmaz: kendi `127.0.0.1` sunucusunu açar, açık ve korumalı uçlara gerçek istek gönderir; korumalı uçlar senin işlevlerini kullanır.
