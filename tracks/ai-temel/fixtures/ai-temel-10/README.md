# ai-temel-10 görünür örnek

lora.json elle hazırlanmış sentetik A/B/temel matrisleridir;canlı eğitim kaydı değildir. Görev1 ölçekli B@A farkı,görev2 aynı farkın temel ile toplamı,görev3 parametre maliyetini işler. fark alanı ilk hesabın doğru önceden yazılmış çıktısıdır;diğer editörden fonksiyon import etmek gerekmez. Kaynağı editörde aç veya yüklenen sözlüğü kodda değiştirip Run dene. Setup mevcut ai_temel_veri.hazirla ile geçici veri/ kopyası kurar;kalıcılık yoktur. Gizli testler ayrıdır. Kare2×2/rank2 örneği parametre tasarrufu garantisi değildir. Final kurulu SmolLM2 kopyasında elle yazılan LoRA ile gerçek40adım CPU eğitimi yapar;PEFT,bitsandbytes,QLoRA kullanmaz. Tek sentetik hedef cümlenin öğrenilmesi genelleme,güvenlik veya backdoor başarısı değildir. Adaptör kalıcı kaydedilmez.
